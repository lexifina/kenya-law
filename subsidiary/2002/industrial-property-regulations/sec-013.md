# 13. Description
(1) This regulation applies with respect to a description referred to in section 34(1)(b) of the Act.
(2) In addition to the requirements under section 34(5) of the Act, the description shall—
(a) state the title of the invention;
(b) specify the technical field to which the invention relates;
(c) indicate the background art which, as far as it is known to the applicant, can be regarded as useful for the understanding, searching and examination of the invention; and
(d) indicate how the invention is industrially applicable.
